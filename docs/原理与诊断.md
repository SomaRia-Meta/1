# 原理与诊断

## 一、故障链路

Windows 的激活子系统由 `sppsvc.exe`（Software Protection 服务）承载。它以**系统服务**身份运行，而 Windows 在加载系统服务时会校验其二进制文件的数字签名。

第三方 KMS 激活工具的典型做法，是把 `sppsvc.exe` 替换成"能骗过授权校验"的修改版。这个文件签名一坏，就出现连锁反应：

```
sppsvc.exe 签名无效
      ↓
SCM 拒绝加载（事件 7000：Windows 无法验证此文件的数字签名）
      ↓
sppsvc 无法启动
      ↓
slmgr.vbs 连接不上服务 → 一直等待 → 命令"卡死"、无输出
      ↓
系统读不到授权信息 → 显示未激活
      ↓
用户尝试用密钥激活 → 密钥与版本不匹配 → 0xC004F069「非核心版本」
```

注意最后一步：`0xC004F069` 是**用户尝试修复时产生的次生错误**，不是根本原因。它的含义是"安装的密钥不属于当前 Windows 版本"——常见于在家庭版上用专业版的 KMS 密钥。

## 二、为什么修文件就能恢复激活

Windows 10/11 的数字许可证（Digital License / HWID）机制，是把**设备硬件指纹**与授权记录的绑定关系保存在微软激活服务器上。

本地文件损坏，不会影响服务器上的记录。所以只要：

1. 原版 `sppsvc.exe` 回来
2. 服务能正常启动
3. 系统能联网

`slmgr /ato` 就能凭硬件指纹重新取回授权，**不需要重新输入任何密钥**。

## 三、组件库（WinSxS）的硬链接机制

`C:\Windows\System32` 里的绝大多数系统文件，并不是独立副本，而是指向 `C:\Windows\WinSxS` 中"组件原件"的**硬链接**——同一份物理数据，两个路径。

这带来一个重要推论：

- 如果篡改工具是**删除后重建**文件 → 硬链接断裂，`WinSxS` 里仍是干净的 → 可以直接从组件库还原
- 如果篡改工具是**原地修改** → 硬链接两端一起变脏 → 组件库里也没有可信副本了 → 只能靠 `DISM` 从微软服务器重新获取

诊断页会把每一份副本的签名状态列出来，就是为了区分这两种情况。

## 四、版本匹配为什么按 UBR

Windows 组件的文件版本格式是：

```
10.0.<分支 build>.<修订号>
```

- **分支 build** 在整个服务周期内固定（Win10 22H2 = 19045 / 19041，Win11 24H2 = 26100）
- **修订号** 随每次累积更新递增（对应系统里的 `UBR` 字段）

例如系统 `Build 26100.9711`，它对应的组件版本就是 `10.0.26100.9711`。

如果只比 build，`26100` 和 `26300` 会被判为"不一致"，但这其实是正常的——所以必须按修订号比。

## 五、诊断要点速查

| 观察项 | 含义 |
|---|---|
| `sppsvc.exe` 签名 `NotSigned` / `HashMismatch` | 文件被替换，这就是根因 |
| 文件修订号 < 系统 UBR | 可能是旧版本残留，但不影响签名校验（灰色提示） |
| 组件库有 ✓ 副本 | 走「② 一键修复」即可 |
| 组件库全 ✗ 或为空 | 走「④ 联网修复」 |
| 事件 7000 有 `Software Protection` 记录 | 服务确实启动失败过 |
| `LicenseStatus = LICENSED` 但仍显示未激活 | 授权数据在，读不出来 → 服务问题 |
| 密钥通道 = `Retail`/`OEM`，末五位≠GVLK | **正常**，零售密钥本来就不等于 GVLK |
| 密钥通道 = `Volume:GVLK`，末五位≠该版本 GVLK | 密钥装错版本，就是 `0xC004F069` |
| KMS 服务器 = 非微软域名 | 第三方 KMS 私服，随时可能失效 |

## 六、`slmgr` 为什么"卡死"

`slmgr.vbs` 是一个 VBScript 包装器，它通过 WMI（`root\cimv2` 的 `SoftwareLicensingProduct` 类）查询授权信息。这个 WMI 提供程序（`sppwmi`）由 `sppsvc` 支撑。

服务不可用时：

- WMI 查询会**阻塞等待**而不是立即返回错误
- 命令看起来就是"卡住了、没反应"
- `Ctrl+C` 有时也中断不了（阻塞在 COM 调用里）

这也是本工具所有 `slmgr` 调用都加了硬超时的原因。
