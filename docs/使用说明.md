# 使用说明

## 一、下载与运行

### 方式 A：直接运行

```bat
双击 run-fix.bat
```

脚本会自动请求管理员权限（UAC 点「是」）。

### 方式 B：手动提权

如果双击没反应，右键 `run-fix.bat` → **以管理员身份运行**。

## 二、五个按钮怎么选

### ① 诊断（只读）

不改任何东西，先看现状。输出内容：

| 项目 | 说明 |
|---|---|
| 系统与环境 | `ProductName`、`EditionID`、`CompositionEditionID`、`Build.UBR` |
| 该版本 GVLK | 你这版 Windows 应该用哪个 KMS 密钥（用于判断密钥装错没） |
| 服务状态 | `sppsvc` 状态；若为 Stopped 会**实际尝试启动一次**验证真假 |
| 文件完整性 | 签名状态、文件版本、签发者、修订号与系统 UBR 是否一致 |
| 组件库副本 | 每一份 `sppsvc.exe` 的签名状态（✓ 有效 / ✗ 无效） |
| 启动失败记录 | SCM 事件 7000（已按服务名过滤，不会混入其它服务） |
| 激活详情 | `slmgr /dlv` 全文 + 密钥与版本的匹配分析 |

### ② 一键修复

执行顺序：

1. 检查 `sppsvc.exe` 签名，有效则跳过替换
2. 无效则从组件库选一份 UBR 匹配的原版
3. 备份 → `takeown` → 覆盖 → 所有者还原给 `TrustedInstaller`
4. 启动 `sppsvc`
5. `slmgr /dlv` → `/ato` → `/xpr`

### ③ 深度修复

用 `slmgr /rearm` 重置授权后重新激活。适合"文件已经修好、服务也起来了，但许可证状态还是乱的"。

> 会影响 Office 等同样依赖 KMS 的组件，它们之后会自行重新激活。

### ④ 联网修复

```powershell
DISM /Online /Cleanup-Image /RestoreHealth   # 从 Windows Update 下载组件
sfc /scannow                                 # 用修好的组件库还原系统文件
```

完成后自动复查组件库，找到有效原版就继续执行 ② 的流程。

- 需要联网
- 通常 10~40 分钟
- 状态栏会实时显示当前进度

### ⑤ 保资料重装

用微软官方 ISO 做**就地升级修复**：

```powershell
挂载 ISO → 运行 setup.exe → 选择「保留个人文件和应用」
```

**保留**：个人文件、已装软件、大部分设置、激活状态
**不做**：格式化、删除分区、清空用户配置

安装前会自动检查：磁盘空间（<15 GB 阻止）、电源（电池供电阻止）、BitLocker、挂起重启、ISO 版本是否低于当前系统。

## 三、ISO 从哪里来

必须用**微软官方原版 ISO**：

- Windows 11：<https://www.microsoft.com/zh-cn/software-download/windows11>
- Windows 10：<https://www.microsoft.com/zh-cn/software-download/windows10>

点 ⑤ 时如果没有找到 ISO，工具会问你要不要打开这个页面。

下载时注意：

| 要点 | 说明 |
|---|---|
| 版本 | 必须 **≥** 当前系统版本，低版本安装程序会拒绝 |
| 语言 | 建议与当前一致（简体中文） |
| 架构 | 必须 x64 |
| 版本类型 | 家庭中文版机器要用「家庭中文版」对应的 ISO |

把 ISO 放在**下载**或**桌面**，工具会自动识别。

## 四、备份位置

```
C:\Windows\Temp\ActivationFixBackup\sppsvc.exe.bak-yyyyMMdd-HHmmss
```

点「备份目录」可直接打开。确认系统正常后可自行清理。

## 五、日志

- 窗口内所有输出都可以点「保存日志」导出到桌面
- DISM 的详细日志在 `C:\Windows\Temp\dism-actfix.log`
- SFC 的详细日志在 `C:\Windows\Logs\CBS\CBS.log`

## 六、操作前请确认

- [ ] 已接上电源（笔记本）
- [ ] 系统盘有 20 GB 以上空闲
- [ ] 重要数据已备份到外部磁盘
- [ ] 记下了 BitLocker 恢复密钥（如果开启了加密）
